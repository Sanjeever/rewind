## 未解决问题

以下状态截至上述验收，后续修复需补充证据再更新。不能按预期行为或单纯外部限制处理在线失败。

- 网易云音源请求在上述验收中返回 `-460`，服务提示网络环境风险。源码迁移完成后，再从宿主机按项目匿名 Cookie 请求三首歌曲均为 `-460`；同批不带该 Cookie 的对照分别得到一个有效地址、`-110` 空地址和 `404` 空地址。这是宿主机请求证据，没有据此修改账号或 Cookie 策略，也没有证明模拟器稳定在线播放。客户端保留顶层和歌曲级错误，触发风控的具体条件、更换网络或登录是否能恢复仍未定位。
- QQ 搜索和音源路径移除了空 catch，搜索检查两层业务码，音源检查授权结果并使用返回的有效 CDN 地址，请求有超时。2026-10-31 宿主机同名歌曲分别取得授权码 `104003` 和有效地址；后者实际 Range 请求返回 HTTP `206`、`audio/mp4` 和 4096 字节。模拟器对照原请求形式和新请求形式，均为顶层 `0`、搜索模块 `2001`，具体拒绝条件未定位；界面展示错误与重试。这些证据尚不能证明稳定在线播放或真实账号可用。
- 本轮 TS/ESM 版本在模拟器切换 QQ 来源后仍返回搜索模块 `2001`。错误反馈与重试已复验，真实 QQ 账号、歌单同步、收藏及稳定音源仍未通过业务验收。
- 完整认证、真实账号升级、在线收藏与歌单同步均未验收。账号包装值的迁移测试不能替代真实登录，歌词获取和显示也不能替代音频与歌词同步验证。
