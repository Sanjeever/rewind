Windows 构建入口、Wrapper 换行与可执行权限已检查，Windows 干净检出尚未实测。真实登录与已购样本播放已有上述证据，账号会话自动刷新、到期恢复、账号切换和完整带账号数据升级仍未验收；在线收藏写入与平台歌单同步写入未验收。实体机播放与听感、耳机/蓝牙、跨应用音频焦点、长时间后台，以及其他 Android 版本仍未验收。本轮没有重做全部媒体导出、系统删除确认、损坏文件和离线音频缓存验收，前述历史结果保留其原有边界。
