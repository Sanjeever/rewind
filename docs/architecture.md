# 架构与兼容约束

本文记录跨模块的职责、设计理由和兼容要求，并链接到实现与回归。变更约束时，说明原因与验证依据。

## 工程边界

项目面向 Android。框架升级保留已有页面、业务语义、音乐来源和用户数据。应用与测试使用严格 TypeScript/TSX，保留既有类组件。统一组件写法本身不能作为改变行为的理由。应用、配置与工具脚本使用 ESM。

业务组件直接从所属功能导入，不由通用组件入口转发；共享业务数据与行为不依赖页面实现，避免页面调整牵连其它功能。弹层内部组件与操作定义跟随 `modals`。

Metro、React Native Gradle 插件和自动链接负责将声明的依赖纳入实际产物，避免兼容包固化第三方实现。应用使用新架构与 Hermes，自有原生模块通过互操作保留 JS 接口，支持业务与原生实现分开迁移。

禁止重新引入兼容 ZIP、旧 Java/JNI 实现、自定义模块映射、专用 JS 打包、运行库注入或手工恢复 Babel 辅助函数及生成的异步状态机。业务逻辑使用显式导入、普通类和 async/await。图片使用 Metro 支持的静态资源导入。JS 注册入口只负责引导。[应用引导](../src/bootstrap/Root.tsx)先完成存储校验与迁移，再动态导入应用，防止业务模块提前读取数据。

## 播放归属与生命周期

- **业务队列只有一份。** JS 管理队列、歌曲选择与播放顺序，原生 Media3 服务管理当前音频、媒体会话与音频焦点。通知和页面共用业务队列，避免各自维护后出现不同步。队列变换基于最新状态，不原地修改输入歌曲；加载歌曲使用提交后的结果。
- **指令和状态分开。** 页面与系统媒体操作进入播放控制边界；原生播放状态通知用于更新界面，不能再转成播放或暂停指令，否则会形成反馈循环。
- **操作通过所属模块进入。** 调用方通过播放或弹层模块发出指令。全局事件用于跨页面状态通知，避免事件名成为隐含的业务接口。
- **异步结果不能恢复旧歌曲。** 切歌、清空和卸载后，旧音源请求及准备回调失效。卸载解除订阅、计时和媒体资源；暂停或后台停止界面进度轮询，后台音频仍由原生服务维护。
- **播放视图通过数据和回调连接控制器。** 视图不依赖控制器实例，布局调整与播放命令处理可以独立演进。
- **退出遵循宿主生命周期。** 关闭时释放媒体资源，由 Activity 正常生命周期卸载界面。提前销毁 ReactHost 曾触发 Fabric Surface 生命周期断言，不以强制销毁宿主替代资源清理。

修改后台播放时，从 [PlayerController](../src/player/PlayerController.ts) 跟踪 JS 状态与[原生播放服务](../android/app/src/main/kotlin/com/kuss/rewind/player/)的交界。切歌、暂停和卸载先查[控制器回归](../src/player/PlayerController.test.ts)，队列提交查[应用层回归](../src/App.test.ts)。锁屏控制、后台音频和焦点切换需要在设备上验证。

## 界面反馈与动效

播放器、队列和通用骨架占位跟随系统减少动态效果设置。过渡可中断，清空队列与卸载时停止未完成动画；旧完成回调不能恢复已关闭界面。封面与歌词交叉切换时保留播放控件和进度条，避免改变操作目标的位置。动效时长不决定网络或播放业务是否完成。

队列的紧凑视图与展开视图共用业务队列，筛选播放按歌曲身份定位原队列，避免搜索改变播放上下文。搜索索引随弹层复用并在关闭后释放，减少连续输入时重复构建索引，也不污染原歌曲。Android 弹层由宿主调整键盘尺寸，避免重复避让压缩可用区域。

异步操作在所属控件反馈等待状态，并阻止重复提交。页面离开或歌曲切换后，旧请求不能覆盖当前反馈。歌单已有内容在刷新时保留，未知歌曲数不显示为零，迟到缓存不能覆盖已接收的网络结果；失败应结束加载并提供原因及重试入口。

播放器过渡见[播放视图状态](../src/player/PlayerPresentation.ts)，队列筛选与操作见[队列弹层](../src/modals/NowPlayingModal.tsx)和[交互回归](../src/modals/queueActions.test.tsx)。系统动效设置由[动效上下文](../src/theme/motion.tsx)提供。

## 歌曲与搜索边界

歌曲身份由来源和来源内标识共同决定，本地歌曲优先使用媒体路径。同名曲目或不同来源的同 ID 曲目不能合并。展示层保留原始歌曲，旧接口与持久化继续使用原始格式。

在线音源按当前平台会话申请授权，音质选择与账号播放权限分开。主来源失败后保留既有备用匹配；试听地址不能当作完整歌曲，备用播放成功也不能证明原来源授权通过。每次准备在线播放时重新取得临时地址，音频数据继续使用原生缓存，避免复用过期地址或前一账号的授权。跨来源音源和本地歌词匹配同时核对歌名、歌手、名称中的版本信息与双方已知时长，不能直接选择搜索首项。

平台可能为部分歌曲返回空歌手名、空专辑名或空订阅字段。按已确认的响应契约保留这些原始值，展示与导航处理缺失元数据，避免一首歌曲阻止整张歌单读取；其它畸形响应仍在边界拒绝。

搜索输入与已提交关键词分开。歌曲、歌单、专辑、歌手、视频结果及建议按当前关键词、来源与生命周期接收响应，迟到响应不能覆盖新状态；清空历史后，旧读取不能恢复已删除记录。搜索区分加载、空结果和请求失败，服务错误不能显示为空列表。分页合并只接受当前请求，避免重复加载。搜索播放与旧页面共用播放命令入口。

QQ 歌曲搜索按服务返回的会话与游标继续翻页，不能用当前结果条数推算源页码。分类搜索保留来源的整数页码，即使平台返回不足一页也不能产生小数页码。

第三方响应先作为 `unknown` 接收，再按接口校验。宽松对象校验保留未知字段。音源与搜索错误保留服务拒绝原因，备用来源失败保留主来源错误，不能用空 catch 或假成功隐藏失败。QQ 账号接口使用当前账号会话，不能内置固定 Cookie 或身份。客户端不得内置云凭据。评论分词在 Android 本地执行，词典随应用打包，保留评论边界并在后台线程处理，避免网络依赖和界面阻塞。

网易云领域模块不反向依赖组合入口，避免初始化循环。主、备用音源共用取消边界，避免切换入口后遗留旧请求。网页与移动端接口共用本人认证会话；扫码 Cookie 可能仅保存在移动端域名，网站请求、CSRF 和移动端加密头均须取得该会话，不能根据单一网站域名缺少 Cookie 判定未登录。

歌曲身份查[字段与身份规则](../src/services/trackFields.ts)，搜索请求从[搜索页面](../src/screens/SearchPage.tsx)进入。修改音源时对照[解析实现](../src/player/trackUrl.ts)和[失败与备用回归](../src/player/trackUrl.test.ts)。认证请求的会话边界见[网易云双域名回归](../src/services/netease/http.test.ts)和[QQ 会话](../src/services/qqmusic/session.ts)。

## 数据保护与升级

验收升级时须保留原有数据，禁止通过卸载、清空数据、改包名或换目录规避迁移。安装条件见[覆盖安装与签名](development.md#覆盖安装与签名)。

旧数据库包含业务包装值、索引及未知键，迁移必须原样保留，不能按已知业务 JSON 重建。旧值写入并读回校验成功后才能标记完成，旧数据库保留供恢复。每次启动先校验本地歌单，已有迁移标记时仍须校验。旧数据读取或歌单校验失败时，应用显示启动错误并阻止正常启动，避免写入空数据。

歌单保留原文件位置，更新时串行写入并原子替换，降低并发与中断写入造成损坏的风险。持久数据与可回收缓存分开，调整[存储路径](../src/storage/paths.ts)时必须考虑已有数据并核对原生实现。媒体扫描、导出与删除使用 MediaStore，删除其他应用创建的媒体时处理系统确认及取消结果。

升级从[存储初始化](../src/storage/index.ts)进入，对照[迁移实现](../src/storage/migrate.ts)和[迁移回归](../src/storage/migrate.test.ts)。涉及文件落盘时，沿[歌单文件操作](../src/storage/playlistFiles.ts)查到[原生存储](../android/app/src/main/kotlin/com/kuss/rewind/RewindStorageModule.kt)，用保留旧数据的安装验证实际写入结果。
