# 清理过程性叙述

假设读者从当前仓库开始，没看过对话、PR 讨论或未归档草稿。他应能找到文中引用的材料，并核验相关事实。

1. 标出「本 PR 新增」「根据前面排查」「我们决定」等依赖写作现场的段落。留意未解释的编号、无法定位的引用、临时 TODO、未证实的意图、评审辩护、逐行复述及重复总结。关键词可帮助定位，按上下文判断。
2. 删除前按 [prose-standard](../prose-standard/SKILL.md) 提取该段的事实、约束和理由。把成立的事实写成读者可独立理解的陈述；可核查的决策链接到设计条目或实现。未知事项保留原有不确定性，当前待办归入 Issue 或[问题与续测](../../../docs/tasks.md)。
3. 完成后回查引用和语义。区分读者必须按序执行的操作、长期成立的设计取舍、可定位的历史证据与作者工作流水账。历史验收保留基线、环境、复现条件、测量和结果。原版发布记录、个人叙事和引用保留原有口吻。

例如，把「评审后决定不复用旧音源」改成当前适用的规则和理由：「每次准备在线播放时重新获取临时地址，避免复用过期地址或前一账号的授权。」
